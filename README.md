# בחירת מוצרים להזמנה - שסטוביץ

אפליקציית דפדפן לבחירת מוצרים מקטלוגי שסטוביץ והפקת הזמנה מוכנה לוואטסאפ
(שם מוצר + ברקוד + כמות).

**קישור:** https://linurbi.github.io/sch/

## שימוש

1. חיפוש לפי שם מוצר, ברקוד או מק"ט, או סינון לפי מותג.
2. לחיצה על מוצר מוסיפה אותו להזמנה; `+` / `−` לשינוי כמות.
3. פתיחת **ההזמנה** ואז:
   - **העתקה לוואטסאפ** - שם, ברקוד או מק"ט, וכמות לכל מוצר
   - **העתקה לאקסל** - `מוצר / ברקוד או מק"ט / כמות`
   - **הורדת קובץ** - אותו טקסט כקובץ `.txt`

ההזמנה נשמרת בדפדפן (`localStorage`), כך שאפשר לחזור אליה.

## מקור הנתונים

כאשר ניתן לפענח בוודאות את הברקוד המודפס, מוצג ברקוד EAN. במוצרים שבהם
הברקוד לא ניתן לפענוח מוצג המק"ט של שסטוביץ, עם תווית ברורה של `מק"ט`.

## עדכון הקטלוג

יש לשמור את קובצי המקור בשם `data/pdf/sch2025.pdf` ו-`data/pdf/sch2026.pdf`.
הייבוא קורא קודם את כל מוצרי 2025, ואז מוסיף רק מק"טים חדשים מ-2026. שכבת
הטקסט והמיקומים ב-PDF מבטיחים שכל שם משויך לתמונה הנכונה.

```powershell
py -3 -m pip install -r scripts/requirements.txt
py -3 scripts/import_pdfs.py
```

התוצאה נכתבת ל-[`data/products.json`](data/products.json) ולתמונות ב-`data/pdf-images/`.
