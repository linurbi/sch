# בחירת מוצרים להזמנה - שסטוביץ

אפליקציית דפדפן לבחירת מוצרים מקטלוגי שסטוביץ והפקת הזמנה מוכנה לוואטסאפ
(שם מוצר + ברקוד + כמות).

**קישור:** https://linurbi.github.io/sch/

## שימוש

1. חיפוש לפי שם מוצר או ברקוד, או סינון לפי מותג.
2. לחיצה על מוצר מוסיפה אותו להזמנה; `+` / `−` לשינוי כמות.
3. פתיחת **ההזמנה** ואז:
   - **העתקה לוואטסאפ** - שם, ברקוד וכמות לכל מוצר
   - **העתקה כטבלה** - `מוצר / ברקוד / כמות` לאקסל או נוטפד
   - **הורדת קובץ** - אותו טקסט כקובץ `.txt`

ההזמנה נשמרת בדפדפן (`localStorage`), כך שאפשר לחזור אליה.

## מקור הנתונים

הברקוד הוא ה-EAN המודפס מתחת לתמונת המוצר בקטלוג, ולא מספר הפריט של שסטוביץ.

## עדכון הקטלוג

הסקריפט מזהה אילו קטלוגים חיים באתר, מוריד את עמודי הקטלוג, מזהה כל מוצר
לפי הפס הכחול מתחתיו, קורא את ספרות הברקוד ומצליב עם שמות המוצרים מטקסט העמוד.

```powershell
py -3 -m pip install -r scripts/requirements.txt
py -3 scripts/fetch_catalogs.py
```

התוצאה נכתבת ל-[`data/products.json`](data/products.json) ולתמונות ב-`data/images/`.

## הרצה מקומית

```powershell
py -3 -m http.server 5173
```

ואז http://127.0.0.1:5173
